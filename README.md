# Gestão Clínica

Página inicial do sistema administrativo do consultório.

## Estado atual

Esta é uma fundação navegável de fase 1. O cadastro de pacientes salva informações somente no armazenamento local do navegador que abriu a página; ele não envia nem sincroniza registros com o repositório GitHub. O repositório não contém registros de pacientes nem dados importados da planilha.

Antes do uso com dados reais, é necessário configurar backend privado, autenticação, controle de acesso, auditoria, armazenamento protegido e backups. Não publique informações de pacientes em arquivos versionados.

## Abrir localmente

Abra `index.html` em um navegador moderno.

## Módulos representados

Visão geral, pacientes, agenda, financeiro, despesas, contratos, mensagens e configurações. A maioria ainda é estrutural e requer implementação de backend e regras de negócio.
